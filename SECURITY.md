# Security policy

Do not attach browser profiles, cookies, tokens, credentials, authenticated URLs,
real extension packages, or private listing content to issues or pull requests.

Report security problems privately to the repository owner. Include the affected
version and a minimal reproduction that contains no real credentials or user data.

Dashbye only accepts loopback CDP endpoints. If a future change permits a
remote endpoint, treat that as a security-sensitive design change requiring an
explicit threat-model review.
